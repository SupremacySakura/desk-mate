# 以完整 GOP 边界恢复并保留最后有效画面

Status: accepted

视频发送端必须完整发送已开始的帧；积压时丢弃尚未开始的旧 GOP 剩余帧并等待新 IDR，不得通过单独丢 P 帧恢复。接收端通过流、帧及分片序号发现不连续，立即请求 IDR、拒绝后续旧 GOP 的 P 帧，并显示 Last Good Frame，直到有效 IDR 到达。该策略以瞬时冻结替代损坏画面，避免把可靠 USB 传输误解为应用层永不丢帧。

Device 进入恢复时递增 Recovery Epoch，软件输出门控释放旧代际输出而不送显，并在解码器控制线程排空或重建硬件解码器。恢复只接受当前配置协商确认的目标 IDR；不能只凭包头 IDR 位就解除门控。Flush、Reset 和重建的 Surface 保留行为及耗时仍须通过 Gate 3 验证。
